# docs/

Documentación del framework.

- `adr/`: registros de decisiones de arquitectura (ADR), numerados.
- `plan.md`: plan de trabajo por sprints (versión interna).
- `sprints.md`: hoja de estado de los 14 sprints para la tutoría.
- `trazabilidad.md`: matriz requisito → componente → issue → prueba (desde el sprint 4).
- `dataset/`: protocolo del conjunto de datos y etiquetado (desde el sprint 2).
