# detector/

Contenedor **Detección e inferencia** (pasos 2 y 3 del flujo). Python.

Recibe la petición derivada por la aplicación objetivo, aplica las reglas del complemento activo, clasifica la carga útil y estima la intención del adversario (reconocimiento, descarga de herramientas, persistencia, exfiltración, movimiento lateral). Sprint 1: reglas y palabras clave provisionales. Sprint 5: clasificador scikit-learn.
