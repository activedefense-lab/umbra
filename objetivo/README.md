# objetivo/

Instrumentación de la **aplicación objetivo** (pasos 1, 2 y 5). Laravel/PHP.

Contiene solo lo que el framework añade a la aplicación objetivo: el endpoint vulnerable de laboratorio (CWE-78), el middleware que deriva la petición sospechosa al detector y la documentación del caso de abuso. La aplicación objetivo en sí vive en su propio repositorio y es únicamente el banco de pruebas; no forma parte del framework.
