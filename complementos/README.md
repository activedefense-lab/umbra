# complementos/

Complementos por tipo de inyección. Cada uno implementa el contrato común (reglas de detección, catálogo de intenciones, plantillas de señuelo) sin modificar el núcleo.

- `cwe78/`: inyección de comandos del sistema operativo (primer caso de uso).
- `cwe79/`: Cross-Site Scripting (segundo caso de uso; sprint 10). Meta de extensibilidad: cero líneas cambiadas fuera de esta carpeta.

Lideran: ambos.
